# 마음챙김 출석 체크

학생이 입장 코드와 출석 내용을 입력하면 Google Apps Script가 코드를 검증한 뒤 Google 스프레드시트에 저장하는 웹앱입니다.

## 변경해야 할 설정 두 곳

### 1. index.html — 웹앱 배포 주소

`webhookUrl`에 본인이 배포한 Google Apps Script 웹앱 주소를 입력합니다.

```javascript
const webhookUrl = '[https://script.google.com/macros/s/본인의_배포_ID/exec](https://script.google.com/macros/s/본인의_배포_ID/exec)';
```

- 끝이 `/exec`인 주소를 사용합니다.
- 학생마다 입력하는 값이 아니라 모든 접속자가 함께 사용하는 주소입니다.

### 2. code.gs — 스프레드시트 ID

`ATTENDANCE_SPREADSHEET_ID`에 출석을 저장할 본인의 스프레드시트 ID를 입력합니다.

```javascript
const ATTENDANCE_SPREADSHEET_ID = '본인의_스프레드시트_ID';
```

스프레드시트 주소가 다음과 같다면 `/d/`와 `/edit` 사이의 값이 ID입니다.

```text
[https://docs.google.com/spreadsheets/d/스프레드시트_ID/edit](https://docs.google.com/spreadsheets/d/스프레드시트_ID/edit)
```

저장소에 값이 이미 입력되어 있어도 본인의 값으로 교체해야 합니다.

## 최초 설정 순서

1. Google 스프레드시트를 만듭니다.
2. 시트 탭 이름을 `입장 코드 입력`으로 지정하고 `A1` 셀에 입장 코드를 입력합니다.
   - `A1`에는 제목이 아니라 코드 자체를 입력합니다.
   - 앞자리 `0`을 유지하려면 셀을 일반 텍스트 형식으로 설정한 뒤 입력합니다.
3. 스프레드시트의 `확장 프로그램 → Apps Script`를 엽니다.
4. `code.gs` 내용을 복사하고 `ATTENDANCE_SPREADSHEET_ID`를 설정합니다.
5. 웹앱으로 배포합니다.
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
   - 계정 또는 조직 정책에 따라 설정이 제한될 수 있습니다.
6. 발급받은 `/exec` 주소를 `index.html`의 `webhookUrl`에 입력합니다.
7. 수정한 HTML을 GitHub Pages 등 웹사이트에 게시합니다.
8. 가상 학생 정보로 틀린 코드 차단과 정상 코드 저장을 확인합니다.

`출석 기록` 탭은 첫 정상 제출 때 없으면 자동 생성됩니다.

## 운영 방법

- 입장 코드는 `입장 코드 입력` 시트의 `A1`에서 변경합니다.
- 코드 확인 요청과 저장 요청 모두 서버에서 입장 코드를 검사합니다.
- Apps Script 코드를 변경했다면 기존 웹앱 배포를 새 버전으로 업데이트합니다.
- GitHub의 `code.gs`를 수정하는 것만으로 실제 Apps Script에 반영되지는 않습니다.
- HTML 설정을 변경했다면 게시한 사이트에도 변경 내용을 반영해야 합니다.

## 참고 사항

- 입장 코드는 간단한 제출 제한 장치이며 학생 본인 인증 기능은 아닙니다.
- 제출 성공 후 학생 브라우저에도 보조 사본을 저장합니다.
- 저장 결과를 확인하지 못했다는 안내가 나오면 재제출 전에 시트 저장 여부를 확인합니다.
- 실제 학생 데이터와 비밀정보는 공개 저장소에 올리지 않습니다.
